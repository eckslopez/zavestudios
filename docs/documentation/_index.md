## Reference Areas

**Doctrine**

- [Architectural Doctrine (Tier 0)](https://github.com/zavestudios/platform-docs/blob/main/_platform/ARCHITECTURAL_DOCTRINE_TIER0.md) defines the non-negotiable platform invariants.
- [Operating Model](https://github.com/zavestudios/platform-docs/blob/main/_platform/OPERATING_MODEL.md) describes how the platform currently works during Formation.
- [Repository Taxonomy](https://github.com/zavestudios/platform-docs/blob/main/_platform/REPO_TAXONOMY.md) classifies repositories and their allowed roles.

**Contracts and lifecycle**

- [Contract Schema](https://github.com/zavestudios/platform-docs/blob/main/_platform/CONTRACT_SCHEMA.md) defines the workload contract surface.
- [Contract Validation](https://github.com/zavestudios/platform-docs/blob/main/_platform/CONTRACT_VALIDATION.md) shows how that contract is checked and enforced.
- [Lifecycle Model](https://github.com/zavestudios/platform-docs/blob/main/_platform/LIFECYCLE_MODEL.md) explains how changes move from adoption through evolution.

**Delivery and automation**

- [Generator Model](https://github.com/zavestudios/platform-docs/blob/main/_platform/GENERATOR_MODEL.md) covers repository, pipeline, GitOps, and capability generation.
- [GitOps Model](https://github.com/zavestudios/platform-docs/blob/main/_platform/GITOPS_MODEL.md) describes how desired state is represented and reconciled.
- [Developer Experience](https://github.com/zavestudios/platform-docs/blob/main/_platform/DEVELOPER_EXPERIENCE.md) documents the local development standard.
- [Pull Request Workflow](https://github.com/zavestudios/platform-docs/blob/main/_platform/PR_WORKFLOW.md) defines the review and merge path.

**Governance and proof of concept work**

- [Enforcement Matrix](https://github.com/zavestudios/platform-docs/blob/main/_platform/ENFORCEMENT_MATRIX.md) shows where rules are binding and where they are advisory.
- [POC Governance](https://github.com/zavestudios/platform-docs/blob/main/_platform/POC_GOVERNANCE.md) defines how exploratory work is contained.
- [POC Graduation](https://github.com/zavestudios/platform-docs/blob/main/_platform/POC_GRADUATION.md) defines what it takes for a POC to join the platform path.
